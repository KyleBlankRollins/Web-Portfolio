Ascribe

A toolchain for documentation written as code. It builds Markdown into a website, plain Markdown, and JSON, and the same compiler runs in the editor, the CLI, and CI, so they always agree. Broken links, missing headings, and undeclared names are errors as you type.

Chapter 3 · 3M, 2017 to 2021

Earlier work

At 3M Health Information Systems I was a technical writer, then a senior technical writer and web developer on the Technical Communications team. These are the web projects and documents from that time that I can share. The rest of the story is in my career timeline.

Redesign · JavaScript · CSS

3M HIS Support website

I worked with the support organization's web team to update the look and feel of our support website. It was harder than it seems: the site ran on an Oracle knowledgebase tool that doesn't like to expose its inner workings.

Custom JavaScript, overridden default styles, and trimming what the tool shipped by default got us there. The site performs better than it did before the redesign and ships less code.

  • streamlined navigation
  • visual hierarchy
